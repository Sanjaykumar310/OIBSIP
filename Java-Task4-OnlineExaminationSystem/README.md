
# Online Examination System — Java

## Overview
A Java Swing desktop application that simulates an online
examination with login, profile update, timed MCQs, and results.

## Features
- Login with demo credentials
- Profile name and email entry
- Multiple-choice questions
- Next and Previous navigation
- Answer retention during navigation
- Five-minute countdown timer
- Automatic submission when time expires
- Submission and quit confirmation
- Score calculation and answer review
- Logout option after results

## Technologies
- Java
- Java Swing
- AWT
- Event handling
- Arrays and collections

## Demo Login

## How to Run

From the project directory:

    javac -encoding UTF-8 -d out src/Main.java
    java -cp out Main

## Project Structure
- `src/Main.java` — application logic and GUI
- `out/` — compiled classes
- `screenshots/` — application screenshots

## Limitations
This is an educational demo. Credentials, questions, and answers
are hard-coded. Profile details and exam results are not saved
to a database.
