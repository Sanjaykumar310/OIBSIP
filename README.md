
# OIBSIP — Java Development Internship Projects

This repository contains Java projects developed as part of the
Oasis Infobyte (OIBSIP) Java Development Internship.

## Projects

### Task 2 — Number Guessing Game
A console-based Java game featuring random number generation,
guess validation, limited attempts, replay, and score tracking.

Folder: `Java-Task2-NumberGuessingGame/`

### Task 3 — ATM Interface
A menu-driven Java ATM simulation featuring authentication,
balance checking, deposits, withdrawals, transfers, and
transaction history.

Folder: `Java-Task3-ATMInterface/`

### Task 4 — Online Examination System
A Java Swing application featuring login, profile entry,
timed multiple-choice questions, question navigation,
submission confirmation, and score review.

Folder: `Java-Task4-OnlineExaminationSystem/`

## Technologies
- Java
- Object-Oriented Programming
- Java Swing and AWT (Task 4)
- Collections and event handling

## How to Run
Each project contains its own README with compilation and
execution instructions.

## Disclaimer
These projects are educational demonstrations and are not
connected to real banking or examination systems.
